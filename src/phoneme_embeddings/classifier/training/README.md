# Исходники обучения из магистерской

Копия исходных ноутбуков и вспомогательных модулей из `Thesis_project_final`.
Сохранены имена файлов и относительное расположение модулей. Скрипты оценки
действующего приложения находятся уровнем выше.

| Эксперимент | Метод |
|---|---|
| `Baseline_Training/main.ipynb` | Покадровый MLP на 256-мерных HuBERTSoft-эмбеддингах. Три головы предсказывают фонему в начале, центре и конце кадра. Обучение минимизирует сумму трёх cross-entropy. Используются AdamW, косинусный график learning rate и dropout. |
| `CTC_models/CTC_Training.ipynb` | Последовательностная модель с двунаправленной LSTM. CTC-лосс сопоставляет последовательность кадров с последовательностью фонем. Оптимизатор Adam и график StepLR. |
| `CTC_models/CTC_Training_tacotron.ipynb` | Авторегрессионный декодер с attention. При teacher forcing декодер получает предыдущую правильную фонему. В коде предусмотрены cross-entropy с маскированием padding и guided attention loss. Оптимизатор Adam и график StepLR. |
| `PhoneticFeatures_Training/` | Многозадачное предсказание фонетических признаков отдельными головами. Есть варианты на два и три класса признака, с cross-entropy по головам. В основном ноутбуке используются AdamW и StepLR. |

Для baseline в журналах обоих checkpoint записаны batch size 32, learning rate
0,001, weight decay 0,0001, dropout 0,1 и 20 эпох. Текущий снимок ноутбука
передаёт 10 эпох в один из вызовов обучения, поэтому его настройки нельзя
принимать за точную конфигурацию сохранённых запусков.

Полный набор CORPRES в ноутбуках указан по исходному сетевому пути.
Файлы в соседней папке `../data/` содержат только кадры с одинаковой меткой
во всех трёх позициях. Для повторения baseline нужны также кадры на границах фонем.
Перед запуском исторических ноутбуков потребуется настроить пути к данным,
выходным папкам и зависимости. Полные прогоны обучения после копирования
не выполнялись.
