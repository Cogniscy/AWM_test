## Исходный эксперимент

- Архитектура — `ClassificationModel` в `DatasetsModels.py`. Вход — 256 признаков HuBERTSoft, четыре общих полносвязных слоя и три выходные головы для начала, центра и конца кадра. Извлечение описано в `Baseline_Training/Extract Embeddings.ipynb`.
- В `models/baseline` сохранены `VACXUXVEXO_model.pth` (42 класса) и `RGCAIQYZHB_model.pth` (46 классов). Порядок индексов взят из `app.py`, сверён с размерностями выходов и списками в ноутбуках и записан в `class_mapping.json`.
- По журналам обоих запусков train — Vladimir, Maria, Mikhail, Anna. Test — Galina, Victoria, Petr, Alexander. Ноутбук обучения объединяет кадры с неоднородной тройкой меток и кадры с одинаковой тройкой, с отдельными квотами. Точный список кадров не сохранён. Загрузчик набирает квоты в порядке обхода файлов.
- Полные пары `*_no_av_embs.npy` / `*_no_av_ph.txt` ожидаются в сетевом каталоге `CORPRES_embs_no_averaging` на `nid-tts-01`. Локально обнаружен демонстрационный пример `ata1101` и сохранённые наборы для эксперимента с фонетическими признаками.
- В исходных журналах `data/outputs/tables/<id>.json` сохранена accuracy центральной головы: 68,48% для VACXUXVEXO и 65,43% для RGCAIQYZHB. Исходные balanced accuracy и macro-F1 не подтверждены. Вывод матрицы в ноутбуке усечён, а графики матриц из соседней копии проекта нормированы по строкам и округлены.

## Повторная оценка

Прочитаны веса обоих checkpoint и выполнен прямой проход центральной головы на CPU через NumPy 2.3.5 по архитектуре PyTorch в режиме оценки, с отключённым dropout. Сравнение выходов с отдельным запуском PyTorch не выполнялось. Проверка использует сохранённые эмбеддинги и не повторяет извлечение из аудио.

В `PhoneticFeatures_Training/data` найдено 180 000 train-кадров и 179 089 test-кадров. Во всех кадрах три фонемные метки совпадают. Записи содержат имя файла без каталога диктора. В двух наборах встречаются общие имена файлов, поэтому по этому полю невозможно подтвердить полное разделение дикторов и высказываний. При расчёте оставлены кадры, у которых все метки входят в словарь соответствующего checkpoint.

| Checkpoint | Кадры | Accuracy | Balanced accuracy | Macro-F1 |
|---|---:|---:|---:|---:|
| VACXUXVEXO | 163 224 | 84,08% | 84,12% | 81,97% |
| RGCAIQYZHB | 179 089 | 79,62% | 79,65% | 77,57% |

Balanced accuracy усредняет полноту по классам в разметке. Macro-F1 усредняет F1 по объединению классов в разметке и предсказаниях. VACXUXVEXO исключает 15 865 кадров с метками вне своего словаря. У checkpoint разные наборы классов и разный состав оцениваемых кадров.

Для повторения запустить `evaluate.py` с Python 3.12 и NumPy. `metrics.json` содержит точные значения, статистику наборов и SHA-256 входных файлов. CSV-файлы содержат ненормированные матрицы ошибок центральной головы.
