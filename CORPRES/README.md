и условиях распространения в рамках этой проверки не устанавливались.

## Структура и используемые файлы

```text
CORPRES/
  Alexander/
  Galina/
  Maria/
  Mikhail/
  Petr/
  Victoria/
  Vladimir/
    <вложенные каталоги>/
      ata1101.wav
      ata1101.seg_B2
      <другие уровни разметки и служебные файлы>
```

Используемая единица входа — WAV и .seg_B2 с тем же именем в одной папке.
Другие найденные форматы включают .meta, .json, .parquet и уровни .seg_B1/.seg_B3,
.seg_G1/.seg_G2/.seg_G3, .seg_Y1/.seg_Y2/.seg_Y3, .seg_R2/.seg_R3.
Их содержимое не используется текущим извлечением и подробно не проверялось.

## Разметка .seg_B2

Файл содержит секции [PARAMETERS] и [LABELS]. Читаются SAMPLING_FREQ,
BYTE_PER_SAMPLE и N_CHANNEL. Позиция в байтах переводится в секунды
делением на произведение этих трёх параметров.
Метка действует до следующей границы. Пустые внутренние интервалы обозначают sil.
Последняя пустая граница завершает размеченную часть записи.
При чтении поддерживаются UTF-8 с BOM и CP1251.

Сохраняются исходные обозначения CORPRES, включая цифровые варианты гласных
и апостроф у мягких согласных.
В проекциях цифровые варианты гласных по умолчанию объединяются в цветовую группу.
Эту группировку можно редактировать. Она не заменяет отдельную фонетическую
проверку инвентаря и таблицы признаков.

## Обработка

Запусти интерфейс по README проекта, выбери «Папка корпуса» и путь CORPRES.
Веса энкодеров лежат отдельно в weights/.
Исходный WAV обрабатывается целиком, адаптер готовит частоту для модели,
получает кадры и временные интервалы. Общий код связывает их с разметкой.
Сохраняются кадры и/или средние по кадрам, целиком лежащим в фонемном сегменте.
Результаты расположены вне исходного корпуса, в data/extracted/.

WAV без парной разметки пропускаются и перечисляются.
Whisper пока требует записи в пределах контекста модели, длинные записи завершаются ошибкой.
Пропуски, ошибки и число готовых run.json требуют отдельной сверки.
Train/validation/test по дикторам в текущей структуре ещё не зафиксированы.
