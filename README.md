# Фонемные эмбеддинги

Локальный исследовательский проект для извлечения замороженных аудиоэмбеддингов,
привязки к фонемной разметке CORPRES и визуального анализа.
Рабочее окружение проверено на macOS arm64 с Python 3.12,
PyTorch 2.8.0 и torchaudio 2.8.0.

## Быстрый запуск

Из папки проекта запусти:

```sh
.venv/bin/python -m streamlit run web_app.py --server.address 127.0.0.1 --server.headless true
```

Открой http://127.0.0.1:8501. Терминал оставь открытым.
После изменения модулей перезапусти сервер через Ctrl+C и ту же команду.

Для нового окружения:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -e '.[web,hubert-soft,whisper-ppg]' 'torch==2.8.0' 'torchaudio==2.8.0'
```

## Боковое меню

**Обработка.** Выбери одну запись или папку корпуса, энкодеры и режимы.
Для корпуса WAV и .seg_B2 должны лежать рядом с одинаковым именем.
Модель загружается один раз на прогон, записи обрабатываются последовательно.
Видны текущие модель, запись и этап. Файлы без разметки пропускаются,
ошибки отдельных записей выводятся в интерфейсе.

По умолчанию включено «Только необработанные». Для продолжения после остановки
выбери прежние корпус, модель, режимы и каталог результатов (`data/extracted`).
Приложение проверит прежние прогоны и пропустит готовые пары с совпадающими
настройками. Проверка большого корпуса может занять несколько минут.
Незавершенные результаты обрабатываются заново в новой папке прогона.
Изменение модели, весов, параметров или исходных файлов требует новой обработки.
Для старых результатов изменение источников определяется по времени файлов.
Чтобы намеренно повторить обработку, отключи «Только необработанные».
Журнал новых попыток сохраняется после каждой записи в
`data/extracted/<модель>/logs/<прогон>.jsonl`: started, complete или error.
При отключении питания текущая запись может остаться со статусом started;
решение о пропуске принимается по сохраненным результатам, а не по журналу.

**Визуализация.** Поиск обработанной записи по пути, имени диктора или дате.
Доступны аудио, осциллограмма, спектрограмма и разметка на общей временной оси.
Выбор кадра или сегмента подсвечивает интервал и показывает координаты его вектора.
Флажок «Выбрать второй вектор» открывает сравнение с кадром или сегментом
этой же или другой записи с теми же весами и параметрами энкодера.
Графики показывают A и B на общих координатах и разность A−B.
Численно выводятся косинусное сходство, L2-расстояние и MSE.
Для нулевого вектора косинусное сходство не определено.
Таблицу координат можно скачать в CSV.

**Векторы.** Каждая точка — кадр или средний вектор одного произнесения фонемы.
Выбери модель, фильтр путей, максимум записей и точек и seed.
Выборка случайная и воспроизводимая при неизменных данных.
Паузы и нечисловые векторы исключаются. Для кадров по умолчанию исключены переходы.
Проекции разных моделей рассчитываются отдельно.

## Настройки PCA и t-SNE

Обе проекции двумерные. Стандартизация каждой исходной координаты отключена по умолчанию.

| Метод | Настройки |
|---|---|
| PCA | whitening; solver auto/full/randomized; seed |
| t-SNE | perplexity; learning rate auto или число; early exaggeration; максимум итераций; метрика euclidean/cosine; инициализация pca/random; angle; предварительное PCA; seed |

Perplexity должна быть меньше фактического числа выбранных векторов.
Предварительное PCA ограничивается числом примеров и размерностью.
Ноль отключает его. t-SNE показывает локальное соседство,
а расстояния между удалёнными группами требуют осторожной интерпретации.
Для PCA показана доля дисперсии двух компонент.

Фонемы имеют разные цвета, варианты одной фонемы — оттенки.
Рабочее правило CORPRES объединяет цифровые варианты гласных a0/a1/a4 и аналогичные.
Мягкие согласные остаются отдельными группами.
Соответствия редактируются в таблице группировки. Это явное рабочее правило анализа.

## Сохранение картинок

В разделе «Векторы» после построения графика укажи название датасета,
папку (по умолчанию ~/Downloads) и форматы PNG/SVG.
Кнопка «Сохранить картинку в папку» сохраняет график текущего набора выбранных фонем.
Имя включает vector-visualization, метод, датасет, модель, режим, число точек,
краткие параметры и время. Длинные имена сокращаются до безопасной длины.
Рядом сохраняется JSON с полными фактическими параметрами, списком записей,
группировкой и цветами. При изменении настроек проекции сначала построй график заново.
Координаты отображаемых точек доступны отдельно в CSV.
Экспорт охватывает весь график выбранных фонем, независимо от текущего приближения.

## Режимы извлечения

- frame — вектор каждого кадра, время, метки трёх частей интервала и ID сегмента при полном попадании.
- segment_mean — среднее кадров, целиком лежащих внутри одного размеченного сегмента.
  Повторения фонемы сохраняются отдельно. Сегменты без целых кадров имеют row=null.
- Оба режима используют один проход энкодера.
- normalization=l2 нормирует кадры и затем средние по сегментам; none отключает нормализацию.

|---|---|---|

| whisper_ppg_base_en.json | weights/whisper_ppg/base.en.pt | whisper-ppg |

| contentvec_256_l9.json | weights/contentvec_256_l9/D_0.pth | contentvec |
| contentvec_768_l12.json | weights/contentvec_768_l12/checkpoint_best_legacy_500.pt | contentvec |

Проверены реальные прогоны HuBERT-Soft и Whisper Base.en.
Остальным адаптерам нужны свои веса и совместимые зависимости.
ContentVec может потребовать отдельное окружение с подходящей версией Fairseq.
Whisper ограничен контекстом модели (30 секунд для текущих весов), длинные записи требуют разбиения.
SyllableLM возвращает непрерывные признаки data2vec2 слоя -2.
KMeans и агломерация не используются в этом выходе.

## Командная строка

```sh
.venv/bin/extract-phoneme-embeddings \
  --config configs/hubert_soft.json \
  --wav data/examples/ata1101.wav \
  --seg data/examples/ata1101.seg_B2 \
  --out-root data/extracted
```

Относительные пути CLI считаются от рабочего каталога.
--out-root создаёт <конфигурация>/<имя WAV>/.
--out позволяет указать точную новую папку. Существующие результаты не перезаписываются.
Пакетный режим доступен через браузер.

## Тестирование классификатора фонем

В боковом меню веб-интерфейса открой «Тестирование модели», выбери
checkpoint и укажи путь к файлу .pt. Файл содержит список кадров с
`embedding` (256 признаков HuBERT-Soft) и `label` (три фонемные метки).
Можно использовать сохранённый `PhoneticFeatures_Training/data/test_embeddings.pt`
из проекта магистерской. В этом наборе метки трёх позиций совпадают во всех кадрах.
Оценка использует центральную голову и кадры, все метки которых входят в словарь модели.

Файлы оценивания собраны в `src/phoneme_embeddings/classifier/`.
В `weights/` лежат оба checkpoint, в `data/` — локальные train/test-эмбеддинги
с фонемными метками, в `recovery/` — отчёт и результаты первоначального
восстановления. Веб-интерфейс подставляет пути к локальным весам и тестовому
файлу автоматически. На другом компьютере скопируй файлы весов и наборы данных
в те же папки или укажи их пути в интерфейсе.

Для этого раздела требуется PyTorch 2.8 или новее (дополнение `classifier`).

Команда оценки с выводом метрик и матрицы ошибок в JSON:

```bash
.venv/bin/python -m phoneme_embeddings.classifier VACXUXVEXO \
  src/phoneme_embeddings/classifier/weights/VACXUXVEXO_model.pth \
  src/phoneme_embeddings/classifier/data/test_embeddings.pt
```

Исходные ноутбуки и модули обучения перенесены в
[`src/phoneme_embeddings/classifier/training/`](src/phoneme_embeddings/classifier/training/README.md).
Там описаны методы обучения и условия воспроизведения.

### Запуск обучения из интерфейса

В разделе «Обучение модели» доступны покадровый MLP с тремя головами,
тот же MLP с обучением только центральной головы и BiLSTM + CTC.
Загрузчик, модель, функция потерь и сборка батча объединены в реестре
`PIPELINES` в `src/phoneme_embeddings/classifier/pipelines.py`. Цикл обучения
общий. В форме задаются словарь, оптимизатор, расписание, параметры и источники данных.

MLP принимает размеченные файлы .pt. Для CTC укажи отдельные папки с парами
`*_no_av_embs.npy` / `*_no_av_ph.txt`. CTC сохраняет порядок кадров и
сворачивает соседние одинаковые центральные метки в одну цель.
Выбирай валидационные данные отдельно от итогового теста. Подставляемый
локальный test подходит для пробного запуска. Лимит кадров выбирает первые
совместимые записи и предназначен для быстрой проверки.

Каждый запуск на CPU создаёт свою папку с историей loss и `best.pth`,
выбранным по validation loss. Для MLP этот checkpoint можно указать
во вкладке «Тестирование модели» с тем же словарём. CTC сохраняет собственный
checkpoint. Исторические ноутбуки attention и фонетических признаков
доступны в папке обучения.

## Граф переходов

В разделе «Граф переходов» исходный пилот содержит 41 метку и 130 направленных
рёбер. Выбери вершину на графе или в списке, чтобы увидеть её признаки, число
сегментов и доступные переходы. В редакторе можно добавить, отключить и развернуть
переход или включить оба направления. Допустимое ребро меняет ровно один признак.
В разделе путей доступны двухшаговые маршруты и фильтр по разным порядкам признаков.

Кнопка «Сохранить версию графа» создаёт JSON в configs/transition_graphs/.
Имя файла — SHA-256 снимка с метками, рёбрами и разбиением. Версии можно открывать
и брать за основу новых правок. Для воспроизводимого эксперимента указывай имя
снимка. Исходный одношаговый пилот использовал configs/corpres_feature_pairs.json.

## Эксперименты MLP

Раздел запускает одношаговый residual MLP на прототипах HuBERT-Soft.
Выбери исходный граф или сохранённую версию. Используются включённые рёбра.
Папка прототипов должна содержать prototypes.npz и metrics.json пилота
с совпадающим прогоном и разбиением по дикторам.

Доступны известные переходы на другом дикторе и отложенные пары.
В последнем режиме оба направления выбранной пары исключаются из train и
validation. В обучении должен остаться пример каждого тестируемого направленного
изменения признака. Перед запуском видны дикторы и число переходов по частям.

Выбери модели с кодом операции и/или без него, ширину, число скрытых слоёв,
seed, эпохи и learning rate. Модели с равными настройками начинают с одинаковых
весов. Лучшая эпоха выбирается по validation MSE. Замороженный VACXUXVEXO
оценивает целевые метки. Таблица включает MSE, accuracy, число параметров,
исходный вектор, средний сдвиг из train и настоящий целевой прототип.
Для каждой обученной модели доступны кривые ошибок и предсказания по переходам.

В reports/mlp_experiments/ сохраняются снимок графа, разбиение, параметры,
хэши входов, метрики и веса. Кнопка скачивания выдаёт метрики в JSON.
